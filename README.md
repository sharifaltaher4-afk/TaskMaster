# Aufgabe Master. Ein smarter Projektplaner in Java

Ein interaktiver, konsolenbasierter Aufgaben- und Projektplaner, der im Rahmen meines Informatikstudiums entwickelt wird. Dieses Projekt dient dazu, die Kernkonzepte von Java und professionelle Softwareentwicklung zu erlernen.

Das Projekt wird schrittweise von einer Konsolen-Anwendung zu einer vollwertigen Web-App mit Datenbankanbindung ausgebaut.

---

## Geplante Funktionen (Roadmap)

### Phase 1: Die Konsolen-UI (Aktuell)
* [ ] Interaktives Hauptmenü im Terminal mit Javas `Scanner`
* [ ] Erstellen, Anzeigen und Löschen von Aufgaben (`ArrayList`)
* [ ] Statusverwaltung (Erledigt / Offen)

### Phase 2: Datenrettung & Persistenz
* [ ] Automatisches Speichern und Laden der Aufgaben als JSON-Datei auf der Festplatte
* [ ] Sortierung nach Prioritäten und Abgabedaten

###  Phase 3: Web-Ausbau
* [ ] Migration des Projekts auf das **Spring Boot Framework**
* [ ] Anbindung einer echten SQL-Datenbank (PostgreSQL / H2)
* [ ] Bereitstellung einer REST-API für Webanfragen
